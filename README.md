# 🗂 Digital Assets

Centralized storage for all images and videos used in websites and apps.

## 📁 Structure

```
digital_assets/
├── images/
├── videos/
└── README.md
```

## 📌 Guidelines
- Use lowercase with camalcase (e.g. bannerHome.webp)
- Optimize before upload (WebP / MP4 preferred)
- Keep high-quality sources elsewhere
- Delete outdated assets regularly
